# Time Tracker

Расширение Chrome для учёта времени по задачам: старт, пауза, продолжение, журнал с фильтрами, экспорт в CSV с переводом на английский, резервные копии.

## Сборка

Нужен Node.js 22.18 или новее.

```sh
npm install      # один раз
npm run build    # собрать расширение в dist/extension
```

Установка: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `dist/extension`. После каждой пересборки нажмите «Обновить» у расширения.

## Проверки

```sh
npm run compile  # проверка типов
npm run lint     # проверка стиля кода
npm test         # тесты (сначала npm run build)
```

## Где что

- `src/popup.ts` — окошко по клику на иконку
- `src/app.ts` — журнал, редактирование, экспорт CSV, резервные копии
- `src/background.ts` — значок на иконке и автокопия
- `src/lib/storage.ts` — хранение задач и формат резервной копии
- `src/tests/` — тесты

В `src/manifest.json` есть постоянный ключ (`key`). С ним ID расширения не меняется, из какой бы папки его ни загрузили, поэтому данные не теряются. Не удаляйте и не меняйте его.
